# Roadmap

TrainLab AI is built across three releases. **Each release is fully functional,
deployable, tested, and documented.** Future features may influence architecture
but are never implemented early.

## Release 1 — Portfolio Ready ✅ Complete

A complete AI platform users can use today.

| # | Milestone            | Status |
| - | -------------------- | ------ |
| 1 | Foundation           | ✅ Done |
| 2 | Authentication       | ✅ Done |
| 3 | Dashboard            | ✅ Done |
| 4 | Project Management   | ✅ Done |
| 5 | Dataset Management   | ✅ Done |
| 6 | Training Engine (Classical ML) | ✅ Done |
| 7 | Transformer Training | ✅ Done |
| 8 | Experiments          | ✅ Done |
| 9 | Deployment           | ✅ Done |

## Release 2 — Industry Ready *(not started)*

Production-grade MLOps: Redis, Celery, background jobs, training queue, MLflow,
model registry, experiment tracking, REST APIs + API keys, LoRA fine-tuning,
hyperparameter search, CI/CD, caching, monitoring, security hardening.

## Release 3 — Research Grade *(not started)*

Advanced AI OS: AutoML, Bayesian optimization, distributed / multi-GPU
training, model recommendation, explainable AI (SHAP/LIME), dataset versioning,
team workspaces, collaboration, Kubernetes, cloud deployment, AI training
assistant, research dashboard.

---

**Working rule:** milestones and tasks are completed one at a time, each pausing
for approval before the next. Releases are never skipped or mixed.
